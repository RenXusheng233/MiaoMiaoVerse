### 图片编辑
- nextjs + fabricjs 画布编辑器

| 用户动作                               | 触发行为                                                    | 画布与右侧面板响应                                                                                                                                                                                |
| :------------------------------------- | :---------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **一进入页面 / 未选中任何组件**        | 画布处于初始状态（ActiveObject = null），维持全局画布配置。 | 1. 画布呈现默认空白尺寸。<br>2. 右侧属性面板展示【全局配置面板】：支持编辑**画布背景色**、**渐变色样式**、**画布圆角**以及**全局尺寸比例**。<br>3. 提供“一键调用AI生成朋友圈配套文案”的全局按钮。 |
| **点击左侧素材组件（文本/气泡/装饰）** | 向画布 Schema 数组中 push 一个对应实例。                    | 1. 画布中央生成对应元素。<br>2. 该元素自动变为【选中状态】，画布渲染出操作外框（控制点）。<br>3. 右侧属性面板**立即切换**为对应组件的编辑内容（不需双击）。                                       |
| **在画布上直接“单选”已有组件**         | 切换当前的 ActiveObject 目标。                              | 1. 被点击组件高亮并显示控制手柄。<br>2. 右侧属性面板**即时联动**。若选中文本则显示【文本编辑】，选中气泡则显示【气泡圆角/颜色编辑】。                                                             |
| **在右侧属性面板内修改表单内容**       | 触发底层 Schema 数据中 props 的实时响应式修改。             | 1. 文本组件：在右侧文本域输入文字，画布字面内容**实时同步刷新**。<br>2. 气泡组件：拖动右侧圆角滑块或滑选颜色，画布气泡形状**即时重绘**。                                                          |
| **在画布中拖拽/缩放/旋转组件**         | 改变当前选中组件的 X/Y 坐标、Scale 比例及 Angle 角度。      | 1. 组件在画布视窗中随鼠标/手势实时进行矩阵变换渲染。<br>2. 右侧属性面板对应的数值（如坐标、宽高、字号等）同步联动刷新。                                                                           |
| **点击画布外白边 / 点击“取消选中”**    | 清空当前的组件选中状态（ActiveObject = null）。             | 1. 隐藏所有组件的控制外框。<br>2. 右侧属性面板**平滑回退**至【全局配置面板】（恢复背景、渐变、圆角及全局AI灵感设置）。                                                                            |
